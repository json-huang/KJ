推荐

A. 最小可用：If/Else + 合流 + 单步调试

  • 节点：Start / Action(ADS读写) / If / Merge / End
  • 连线：True/False 两条边；Merge 合并回主线
  • 调试：运行/暂停/单步，当前节点高亮；右侧显示最近一次执行结果
Start → If (cond) ─True→ ADS.Read → Merge → ADS.Write → End └False→ ADS.Write ──────────────┘
更灵活

B. 图结构：多出口节点 + 多合流节点

  • 任意节点可定义多个“出口”(Ports)，每条边带标签
  • 合流节点支持等待多个输入（可选 AND/OR）
  • 调试：每条边可显示“走过次数/最后一次条件值”
Node has ports: out1/out2/out3; edges labeled “ok/err/timeout”
偏工程化

C. DSL/规则优先：条件写成表达式

  • If 条件写成表达式（如 Tag/变量/常量）
  • 运行时可查看表达式求值过程（trace）
  • 适合后续接入脚本（Lua/JS）
If: (Tag("MAIN.nSpeed") > 1000) && (Var("retry") < 3)
先把调试做强

D. 调试先行：运行记录 + 回放

  • 先把执行引擎/运行日志/回放做完整
  • 分支先用“单 NextStepId”占位，后续再扩展 If/Else
  • 适合你马上要接真 PLC/现场调试
Run #42: stepId=... duration=12ms result=OK value=1234
